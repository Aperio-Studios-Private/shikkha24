## Live data verified

The header utilities are pulling **real API data**, not placeholders:

- Weather → Open-Meteo: **ঢাকা ৩১° মেঘলা**
- Prayer → Aladhan: **ইফতার/মাগরিব ১৮:০৫**
- Hijri → Aladhan, with Bengali month names: **১ রবিউস সানি ১৪৪৮**

Both are memoised (`lib/widgets.ts`) so a 5,000-page build costs **2 API calls**, not 10,000. Both return `null` on failure — a dead weather API omits the widget and never fails the build.

## Two things to know

**1. Trending is provisional.** A genuine "most read" ranking needs view counts, and a static site has nowhere to accumulate them — there is no server in the request path. The trending list is currently fed the most recent articles. The real fix is either Apache access log analysis feeding a build-time ranking, or an editorial "trending" flag. Both are noted; neither belongs in S3.

**2. Demo content exists and must be deleted before launch.** `pnpm seed:demo` added 12 articles, 5 deadlines and 1 author so the homepage could be reviewed as a design. The production seed (`pnpm seed`) remains **taxonomies-only**, per the S1 principle that editorial content is the team's job. Every demo slug is prefixed `demo-`.

**Removal is one command** (added 2026-09-15): `pnpm --filter @shikkha24/cms seed:demo:purge`. It is a dry run unless `--confirm` is passed, matches 55 rows across 15 collections, and leaves the taxonomies (`categories`, `levels`, `districts`) and the site logo untouched. See `cms/src/seed/demo-purge.ts`.

## Deviations / notes

- **Deadline `type` values must match the CMS.** `DEADLINE_TYPES` in `Deadlines.ts` is a `select`: `admission, result, examRoutine, scholarshipDeadline, holiday, circular`. Invalid values are rejected at validation — this broke the first demo-seed run. `DeadlineStrip.astro` keeps a parallel Bengali label map that must stay in step.
- **Level filters are a toggle, not a trap.** Clicking the active pill clears it, so a reader is never stuck in a filter with no obvious way out.
- **A story with no level/district is treated as "no restriction"** by the filter, so general education news never disappears for a reader who has picked a district.
