## Planned deliverables

| Piece | Notes |
|---|---|
| `Reactions` collection | `article`, `type` (like / love / wow / sad / angry), `reader`, `fingerprint` |
| `fingerprint` | **Hashed** IP + UA. ⚠️ **Never** store a raw IP — see `docs/security.md` §8 |
| Dedupe | Compound unique indexes on `(article, type, reader)` and `(article, type, fingerprint)` — rejected at the **database** level, not merely in the UI |
| `POST /api/reactions/toggle` | Mounted **on the collection**, not at the root — a root path whose first segment equals a collection slug is shadowed by that collection's generated route (the `/comments/submit` 404) |
| Throttling | Per-IP rate limit + honeypot, matching `citizen.ts` |
| Frontend | Self-hiding island: renders nothing without a CMS origin. Accessible `radiogroup` + live region |

⚠️ **Aggregate counts must be read at runtime.** Baking them into static HTML would
freeze stale numbers until the next build.
