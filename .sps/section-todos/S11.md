### 2. OG/Twitter cards + canonical URLs (commit `5c8c3af`)

- Layout already emitted OG/Twitter meta + canonical. No changes needed to the meta tags themselves.
- Article page passes `ogImage` (resolved photo via `resolveCmsImage`), `canonical`, `publishDate`, `modifiedDate`.

### 3. `llms.txt` (commit `5c8c3af`)

- Created at `/llms.txt` per `docs/seo-plan.md` §5.

- `robots.txt` already allows AI crawlers (GPTBot, PerplexityBot, ClaudeBot, Google-Extended) — built ahead of sequence in S6.

### 4. URL architecture (commit `a20f0df`)

- **New scheme:** `/:category/:id/:slug` (was `/article/:slug`).
  - The `:id` is the stable part — headline edits change the slug, not the URL.
  - The education category tree is flat (no subcategories), so the `:subcategory` segment from the plan is omitted.
- **New route:** `pages/[category]/[id]/[slug].astro` — full article page at the new URL.
- **Legacy redirect:** `pages/article/[slug].astro` → meta refresh + canonical to new URL. Old links from WhatsApp/Facebook/Google don't break.
- **Shortlink:** `pages/a/[id].astro` → redirect to full article URL. Stable, never reused. For social sharing.
- **Shared `articleUrl()` helper** in `lib/url.ts` — single source of truth for all 15+ references.
- **All 15 `/article/${slug}` references updated** across: ArticleCard, BreakingTicker, TrendingList, LatestFeed, index.astro, 404.astro, bookmarks.astro, category page, sitemap.xml.ts, rss.xml.ts, news-sitemap.xml.ts.
- **Bookmarks** use the shortlink `/a/:id` (the bookmark entry stores only id + slug, no category).

### 5. 500-cap pagination fix (commit `a20f0df`)

- Old `getAllArticleSlugs()` had `limit: 500` with no pagination → sitemap silently stopped growing past 500 articles.
- New `getAllArticlePaths()` paginates through the full result set using Payload's `page` + `limit` parameters.
- Also returns `id` + `categorySlug` alongside `slug` — enough to build the new URL without an extra fetch per article.
- `getAllArticleSlugs()` kept as a thin wrapper for backward compatibility.

### 6. Feeds (built ahead of sequence, S6/S11)

Already done: `robots.txt`, `sitemap.xml`, `news-sitemap.xml`, `rss.xml`. All updated to use the new URL scheme via `articleUrl()`.
