## What was built

### Design tokens (`frontend/src/styles/global.css`)
- **Brand colours:** brand-red `#DA1C25`, brand-charcoal `#1F1F1F`, dark-base `#121212` (BBC-style)
- **Semantic colours:** ink / ink-muted / ink-subtle / rule / surface / surface-raised + dark counterparts
- **Typography:** Hind Siliguri (headlines), Noto Sans Bengali (body), system UI (Latin/UI text)
  - Inter **deliberately absent** — owner-approved 2026-09-12; its variable file is 83 KB/weight and would break the 200 KB font budget
- **Type scale:** base = 17px (Bengali floor, not a suggestion), line-height ≥1.65
- **Layout:** 12-column responsive grid (4→8→12 cols), container max 1248px, prose max 672px
- **Accessibility:** visible focus rings, `prefers-reduced-motion` honoured, skip link, text-wrap: balance

### Components
| Component | File | Notes |
|---|---|---|
| Logo | `components/Logo.astro` | CMS-first — the uploaded asset renders as a **mark beside** the name, never replacing it; the wordmark is derived from `siteName` with an auto-accented trailing digit/Latin run; `showNameWithLogo=false` is the only way to hide the name (amended 2026-09-13) |
| ThemeToggle | `components/ThemeToggle.astro` | Dark/light toggle; persists to localStorage; follows OS by default; restores before paint |
| TextResizer | `components/TextResizer.astro` | 3-step scale (1→1.1→1.2); persists to localStorage; restores before paint |
| Header | `components/Header.astro` | Utility ribbon (date, optional weather/prayer widgets, social links) + main header (logo, search, theme, resizer) + nav bar with mega menu dropdowns + mobile hamburger drawer |
| Footer | `components/Footer.astro` | Brand zone + category links + footer pages + social links + copyright + legal links + CMS-managed footer text |
| MobileShareBar | `components/MobileShareBar.astro` | Sticky bottom bar on mobile: WhatsApp, Facebook, copy link |

### Layout (`layouts/Layout.astro`)
- HTML5 boilerplate with `lang="bn"`
- SEO meta tags: description, OG, Twitter, article dates, canonical
- Font preloading for Hind Siliguri + Noto Sans Bengali Bengali subsets
- Inline anti-FOUC script (theme + text scale restored before first paint)
- JSON-LD structured data hook
- Skip link → `#main-content`
- Header → `<main>` → Footer → MobileShareBar

### Content layer (`lib/cms.ts`)
- Build-time fetch layer: Payload REST → static HTML at build time
- **Hard requirement:** never fail the build — every helper degrades to documented fallback with a console warning
- Fallbacks mirror the approved 8-category tree and owner-confirmed site settings
- `getSiteSettings()`, `getCategories()`, `getFooterPages()`

### Index page (`pages/index.astro`)
- Uses the new Layout
- S2 preview / smoke test: hero, typography probe, feature flags, 12-col grid demo
- NOT the final homepage (S3)
