## What was built

| Item | Detail |
|---|---|
| `pagefind@1.5.2` | Dev dependency, **MIT** licensed |
| `pagefind --site dist` | Added to the frontend `build` script, so the index is always in step with the site |
| `pages/search.astro` | The search page |
| `data-pagefind-body` | On the article page, so only stories are indexed |
| `data-pagefind-ignore` | On the related-articles sidebar |
| `slot name="head"` | Added to `Layout.astro` so a page can inject its own CSS |

**Verified:** 12 pages / 356 words indexed. Search page renders with
`pagefind-ui.css` + `pagefind-ui.js`. lint, typecheck (both workspaces), CMS
build, WAL gate all pass.

## Why Pagefind

The site is static HTML on Cloudflare Pages with no server in the request path,
which rules out anything needing a backend. Pagefind builds the index at build
time and queries it in the browser from small per-page fragments — zero runtime
cost, and it works offline once loaded.

It is also the right cost answer: no Algolia, no Elasticsearch, no monthly bill.
The no-card constraint makes a hosted search service a non-starter.

## Index scope

Before `data-pagefind-body`, Pagefind indexed all 24 pages including category
listings, the 404 and the homepage — so a query could return "this story is
mentioned in the footer of a category page". Scoping to the article body cut it
to 12 pages of actual stories. The related-articles sidebar is explicitly
ignored, since those headlines belong to *other* stories and would make an
article match queries it is not about.

## ⚠️ Known limitation: no Bengali stemming

Pagefind prints this at build time:

> Pagefind doesn't support stemming for the language bn. Search will still work,
> but will not match across root words.

This is real, and not something configuration can fix. Search matches exact word
forms — "শিক্ষা" will not match "শিক্ষার্থী".

Mitigations, in order of effort:
1. **Browse fallback (done)** — category chips on the search page, so filtering
   is a first-class route when search comes up short.
2. Synonym list at index time.
3. Keep the 8-category taxonomy tight so browse-and-filter carries discovery.

## Notes

- Pagefind UI ships English strings only; all UI copy is translated to Bengali
  in `search.astro` (placeholder, one/many/zero results, searching, load more).
- The UI script and chunk load **only** on `/search`, not site-wide.
- Index size is ~708 KB on disk, but it is fetched as small per-query
  fragments, not as one file.
