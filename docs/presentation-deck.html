Technology

The Stack — Fast, Free, Future-Proof

A

Astro 7.3

Static site generator. Zero-JavaScript by default. Pages are pre-built HTML — fastest possible delivery.

P

Payload CMS 3

Headless CMS with built-in versioning, workflows, RBAC and media management. Free, MIT-licensed.

T

Tailwind CSS 4

Utility-first styling. Small CSS bundles. Consistent design system across all components.

S

SQLite → PostgreSQL

SQLite for launch (simple, fast, zero config). PostgreSQL when we scale — same code, swap adapter.

C

Cloudflare Pages + R2

Frontend on Pages (free, unlimited bandwidth). Media on R2 (10 GB free, zero egress fees).

D

DianaHost 2 GB

Payload CMS backend. Built slim in CI with Next.js standalone (~300–600 MB). Fits comfortably.

Architecture

How It All Connects

Reader → Cloudflare Pages (static HTML) → Edge cache → <200ms TTFB
Editor → Payload Admin (DianaHost) → Write & Publish → Webhook → CI rebuild
Media → Cloudflare R2 (images, videos, documents) → CDN delivery → zero egress cost
CI/CD → GitHub Actions (Node 24) → Build + Quality gates → Deploy to Pages + DianaHost

Key insight: The CMS can go down without the site going down. Readers get static HTML from Cloudflare's edge. Only editors touch the backend. This is why we can run on a 2 GB shared host while serving unlimited traffic.
