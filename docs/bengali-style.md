# বাংলা লেখার মান (Bengali Style Standard)

**তৈরি:** ২০২৬-১০-১৮ · **অবস্থা:** বলবৎ · **প্রযোজ্য:** শিক্ষা২৪.কম-এর সব ব্যবহারকারী-দৃশ্যমান বাংলা

> এই নথিটি লেখার **মান** ঠিক করে, যাতে Antigravity, যেকোনো এজেন্ট, এবং ভবিষ্যতের
> যে কেউ একই ধরনের বাংলা লেখে। নথিটি T-46 ("Naturalize Bengali language")
> কাজের সময় নির্ধারিত মান থেকে লেখা হয়েছে — এটি নতুন নিয়ম বানায়নি, বরং
> ইতিমধ্যে যা প্রয়োগ করা হয়েছে তা লিপিবদ্ধ করে।

## ১. কেন এই নথি

প্রথম দিকে সাইটের বাংলা ছিল **অনুবাদ-ধাঁচের ও দাপ্তরিক** — যন্ত্রের মতো। কারণ তিনটি:

1. **ইংরেজি বাক্যগঠনের ছায়া** — "সিস্টেম সংরক্ষণ করবে না যদি Alt text না লেখা থাকে"
2. **দাপ্তরিক শব্দ** — "প্রয়োজনীয়", "নিম্নলিখিত", "অবগত"
3. **AI-লেখার চিহ্ন** — em dash (`—`) ও ঝুলন্ত ellipsis (`…`)

মালিক এটি ধরেন এবং T-46 শুরু হয়। Phase ১–৩ শেষ হয়েছে (২৯টি ফাইল), Phase ৪ চলছে।

**লক্ষ্য এক বাক্যে:** যেন একজন সহকর্মী পাশে বসে ধীরে ধীরে বুঝিয়ে দিচ্ছেন — দাপ্তরিক নয়, বইয়ের নয়, অনুবাদের নয়।

## ২. কণ্ঠস্বর (Voice)

| দিক | নিয়ম |
|---|---|
| সম্বোধন | **"আপনি"** — শ্রদ্ধাশীল কিন্তু আন্তরিক, দূরত্ব নয় |
| বাক্য | ছোট। এক বাক্যে একটাই ভাবনা |
| ক্রিয়া | মুখের স্বাভাবিক ক্রিয়া: "দেখে নিন", "চেপে দিন", "বেছে নিন", "মনে করিয়ে দিন" |
| ক্রম | মূল কথা আগে, ব্যাখ্যা পরে |
| শিরোনাম | খবরের কাগজের শিরোনামের মতো — ছোট, স্পষ্ট |
| বোতাম | সংক্ষিপ্ত: "সংরক্ষণ", "পাঠান" (বাক্য নয়) |
| ভুল বার্তা | নরম কিন্তু স্পষ্ট: "পাসওয়ার্ডটি মেলেনি, আবার চেষ্টা করুন।" |
| নিশ্চিতকরণ | যন্ত্রের সান্ত্বনা নয় — মানুষের আশ্বাস |

**নিষিদ্ধ দাপ্তরিক শব্দ:** উক্ত, প্রয়োজনীয়, নিম্নলিখিত, অবগত, প্রদান করুন, সংশ্লিষ্ট,
পর্যাপ্ত, বিধেয়, সম্পাদিত, তদনুসারে, উহা, ইতোমধ্যে

**নিষিদ্ধ গঠন:** "…এর মাধ্যমে", "…কে কেন্দ্র করে", "…ক্ষেত্রে", "…হেতু",
"এটি প্রয়োজন যে আপনি…"

## ৩. যুক্তির চিহ্ন — সবচেয়ে কম আলোচিত নিয়ম

**এগুলো লেখকের অলসতার চিহ্ন। ব্যবহার করবেন না:**

| বাদ | কারণ | বদলে |
|---|---|---|
| `—` (em dash) | AI-লেখার সবচেয়ে সহজে ধরা পড়া চিহ্ন | `:`, `\|`, কমা, দাঁড়ি |
| `…` বাক্যের শেষে | ঝুলন্ত, অনির্দিষ্ট | দাঁড়ি `।` |
| `--` | ইংরেজি টাইপোগ্রাফি | উপরের মতোই |

**উদাহরণ:**

```
❌ রিফ্রেশ করুন — এতে সমস্যা সেরে যাবে।
✅ রিফ্রেশ করুন, সমস্যা সেরে যাবে।

❌ খবর খুঁজুন…
✅ খবর খুঁজুন
```

> **ব্যতিক্রম:** উদ্ধৃতিতে বা উৎসের হুবহু লেখায় মূল যুক্তি অপরিবর্তিত থাকবে।

## ৪. বানান — বাংলা একাডেমি প্রমিত রীতি

T-46-এ যেসব সংশোধন প্রয়োগ করা হয়েছে (এগুলোই মান):

| ভুল/অপ্রমিত | প্রমিত | ধরন |
|---|---|---|
| কিভাবে | **কীভাবে** | প্রমিত বানান |
| শর্তাবলী | **শর্ত** | বহুবচন বাহুল্য |
| সনাক্ত | **বর্তমান অবস্থান** | ইংরেজি calque বাদ |
| পাওয়া যায়নি | **পাওয়া যায়নি** | য়-কার |
| বৃত্তির সময়সীমা | **বৃত্তির সময়সীমা** | প্রমিত |
| সবচেয়ে দ্রুততম | **নির্ভরযোগ্য ঠিকানা** | দ্বৈত অতিশয় = ব্যাকরণগত ভুল |
| শিক্ষা সুবিধা | **শিক্ষা সেবা** | calque বাদ |
| প্রধান নেভিগেশন | **প্রধান মেনু** | calque বাদ |
| পেজ N | **পৃষ্ঠা N** | প্রমিত পরিভাষা |
| সংবাদ তালিকা | **খবরের তালিকা** | স্বাভাবিক |
| ট্যাগে প্রকাশিত সংবাদ | **ট্যাগ বিষয়ক সব খবর** | স্বাভাবিক |

> ⚠️ **সংস্করণ সম্পর্কে সতর্কতা:** এই নথি বাংলা একাডেমির নির্দিষ্ট কোনো
> সংস্করণের সংখ্যা দাবি করে না। এখানে যা আছে তা **প্রয়োগকৃত সংশোধনের তালিকা**,
> কোনো সংস্করণ-দাবি নয়। নতুন সংশোধন এলে এই টেবিলে যোগ হবে।

## ৫. সংখ্যা ও শ্রেণিবাচক

**নিয়ম: বাংলা সংখ্যা ব্যবহার করুন, এবং শ্রেণিবাচক 'টি' জোড়া লাগান (ফাঁক নয়)।**

```astro
❌ {count} টি খবর          →  ফাঁক ভুল
❌ {count}টি খবর           →  ইংরেজি সংখ্যা
✅ {toBnDigits(count)}টি খবর

❌ ৩ মিনিট পড়া            →  ঠিক আছে (একক)
✅ {toBnDigits(mins)} মিনিট  →  সংখ্যা + একক, ফাঁক থাকবে
```

**সহায়ক ফাংশন:** `toBnDigits(value)` — `frontend/src/lib/bangla-date.ts`

> ⚠️ **জ্ঞাত অসঙ্গতি:** দুটি প্রায়-অভিন্ন `toBnDigits` আছে —
> `lib/bangla-date.ts` এবং `lib/widgets.ts`। কম্পোনেন্টগুলো প্রধানত
> `bangla-date` থেকে নেয় (৪০টি ফাইল), `widgets` থেকে ৫টি। দুটির আচরণ এক,
> কিন্তু বাস্তবায়ন আলাদা — একত্রীকরণের যোগ্য (আলাদা কাজ)। ততদিন নতুন কোডে
> **`bangla-date` ব্যবহার করুন**।

## ৬. যেসব শব্দ ইংরেজি থাকবে

কারণ ক্লায়েন্ট CMS-এ ঠিক এই শব্দগুলোই দেখেন — গাইড ও অ্যাডমিনে একই শব্দ থাকা দরকার:

`Alt text` · `Featured Image` · `Breaking` · `Headline` · `Slug` · `Standfirst` ·
`Excerpt` · `Body`

প্রথমবার এলে বন্ধনীতে বাংলা দেওয়া যায় — `Publish (প্রকাশ)` — দ্বিতীয়বার নয়।

## ৭. যা কখনো বদলাবে না

ভাষা বদলায়, **তথ্য নয়**:

- সংখ্যা, তারিখ, পরিসংখ্যান, উদ্ধৃতি, নাম — হুবহু
- `id`, `class`, `href`, `data-*`, টেমপ্লেট অভিব্যক্তি `{...}`
- element ID, শৈলী, গণনার চুক্তি (calculators)
- HTML গঠন

> **মূল নীতি:** তথ্য বদলাবে না, ভাষা বদলাবে।

## ৮. স্বয়ংক্রিয় যাচাই

| যাচাইকারী | কী ধরে |
|---|---|
| `pnpm run verify:bengali-spacing` | শব্দ জোড়া লেগে যাওয়া (`জানতেযোগাযোগ`) |
| `pnpm run verify:site-name` | সাইটের নাম হার্ডকোড হয়েছে কি না (CMS মান হওয়া উচিত) |
| `pnpm run verify:search-init` | অনুসন্ধান প্লেসহোল্ডার |
| `pnpm run build` | Astro গঠন অটুট আছে কি না |

**প্রতিটি ভাষা-পরিবর্তনের পর কমপক্ষে:** `pnpm run build` + `verify:bengali-spacing`

> **কেন `verify:bengali-spacing` বিশেষ:** বাংলায় শব্দ-বিভাজক নেই, তাই
> Astro-র minifier যখন whitespace-only text node গিলে ফেলে, ইংরেজিতে সেটি
> "missing space", কিন্তু বাংলায় সেটি **অন্য অর্থহীন শব্দ**। উৎস বৈধ, HTML বৈধ,
> typecheck পাস, Biome পাস — ভুল শুধু পর্দায় ধরা পড়ে।

## ১০. এই নথি লেখার সময় ধরা পড়া বাস্তব ভুল

এই নথি লেখার সময় তিনটি আসল সমস্যা ধরা পড়ে — ভবিষ্যতের জন্য লিপিবদ্ধ:

1. **ভাঙা import.** Phase 4-এ `lib/formatters` নামে একটি মডিউল থেকে
   `toBnDigits` আমদানি করা হয়েছিল, যা এই রেপোতে **কখনো ছিল না**। ফলে
   `pnpm run build` ব্যর্থ হয়। সঠিক মডিউল `lib/bangla-date`।
   **শিক্ষা:** নতুন import লেখার আগে মডিউলটি সত্যিই আছে কি না দেখে নিন।
2. **হার্ডকোডেড সাইটের নাম.** `terms-of-use.astro`-এ `শিক্ষা২৪` সরাসরি লেখা ছিল,
   যা `verify:site-name` ধরে ফেলে। CMS-এর `settings.siteName` ব্যবহার করতে হবে।
3. **অনুপস্থিত ফাইল ধরে নেওয়া.** "তিনটি `toBnDigits`" লেখার আগে যাচাই করে দেখা
   যায় কেবল **দুটি** আসলে আছে। **শিক্ষা:** দাবি করার আগে গণনা যাচাই করুন।

## ১১. নথি হালনাগাদের নিয়ম

T-46 চলাকালীন এই নথি **স্থির** থাকবে। Phase ৪ শেষ হলে:

1. নতুন সংশোধন এলে §৪-এর টেবিলে যোগ করুন — পুরনো সারি মুছবেন না
2. নতুন কোনো নিয়ম যোগ হলে §৩ বা §৫-এ, এবং T-46-এ উল্লেখ করুন
3. `toBnDigits` একত্রীকরণ হলে §৫-এর সতর্কতা সরান
