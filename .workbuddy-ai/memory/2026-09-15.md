## Demo-purge tooling (audit §2.8)

**The documented removal path did not exist.** `cms/src/seed/demo.ts` told the reader to run
`payload run src/seed/demo-purge.ts` — and no such file had ever been written. "Delete before
launch" therefore meant hand-deleting ~130 records across 22 collections in the admin UI.

**Built:** `cms/src/seed/demo-purge.ts` + `seed:demo:purge` npm script.

- **Dry run by default**; `--confirm` required to delete. Deliberate asymmetry — the operation
  is irreversible and a wrong match loses real editorial content.
- Removes **55 rows across 15 collections**: the demo content plus the reader rows that point at
  it (comments, poll votes, bookmarks, saved deadlines), children first.
- **Deliberately leaves alone:** the taxonomies (`categories`, `levels`, `districts` — real
  owner-approved data) and the **site logo** (`logo-placeholder-1.svg` in `media`).
- `demo.ts` now exports `DEMO_DEADLINE_TITLES` / `DEMO_QUIZ_TITLE` / `DEMO_POLL_QUESTION` —
  those three collections carry no `demo-` marker, so purge and seed share one source of truth.
- Post-purge leftover report so a row the matcher missed is visible, not silent.

**Verification method (reusable):** copied `cms/data/` (DB **and** media — Payload deletes upload
files from disk) to `/tmp`, then ran against the copy via `DATABASE_URI` + `MEDIA_UPLOAD_DIR`.
Proved: dry run → 55 reported; confirm → 55 deleted, taxonomies + logo intact; second run → clean
no-op; `seed:demo` → all 55 recreated; confirm again → 55 deleted. The dev DB was never touched
(verified by row counts + `PRAGMA integrity_check`).

**Two bugs the tests caught:**
1. The demo-author guard asked "does any article reference this author?" — always true on a dry
   run, because the demo articles are still present. Fixed by excluding the exact ids already
   scheduled for deletion (`id: { not_in: articleIds }`). A nested `and` with `slug: { not_like }`
   silently did not filter, which is why the id-based form was chosen.
2. The leftover report omitted `media`, so it claimed "every content collection is empty" while
   the site logo remained. Added `media` to the list with an explanatory line.

Lint delta: **0** (4 errors / 13 warnings both before and after — all pre-existing).
