## Bug: S2 page rendered unstyled — missing CSS import in Layout

- **Symptom:** owner reported the index page had no styling at all.
- **Root cause:** when S2 introduced `Layout.astro`, the `import '../styles/global.css'` that lived in `index.astro` was never moved into the Layout. Astro does NOT inherit page-level CSS imports into components — with nothing referencing the stylesheet, Tailwind emitted no CSS at all. `dist/` had zero `.css` files.
- **Fix:** one line in `Layout.astro`. After: `dist/_astro/*.css` = 23,975 bytes / 182 utility classes; HTML links the stylesheet. Commit `073d20a`.
- **Lesson (now in MEMORY.md):** every stylesheet that should reach the build must be imported in the rendered tree, typically the layout.

## Font decision: SolaimanLipi only (replaces Hind Siliguri + Noto Sans Bengali)

- **Owner rejected Hind Siliguri:** text hard to read, and a numeral would not render. Measurement backed this: it covers only **92/128** Bengali codepoints and lacks ৲ ৼ ৽ ৾.
- **Interim:** consolidated to a single family (Noto Sans Bengali, 110.5 KB, 96/128) — verified all 10 numerals, all conjuncts, all vowel signs.
- **Final: owner named SolaimanLipi.** Not on Google Fonts; it is **SIL Open Font License** (Solaiman Karim / Ekushey / OmicronLAB). Chosen for reader familiarity — it is what the major Bangladeshi newspapers are set in.
  - Vendored at `assets/fonts/vendor/` with `OFL.txt` (OFL requires the licence travel with the font). Build now needs no network.
  - Subset to Bengali + Latin → WOFF2: **154.0 KB** for both weights (68.3 + 85.8), inside the 200 KB budget with 46 KB headroom.
  - **Critical:** subsetting kept `--layout-features=*`. Verified the full Indic set survives — `akhn, blwf, half, liga, nukt, pstf, vatu`. Bengali conjuncts are formed by shaping, not single codepoints; dropping those features would silently break every যুক্তাক্ষর.
  - Rejected alternatives: Anek Bangla (111.2 KB, 90/128 — larger AND less complete), Tiro Bangla / Noto Serif Bengali (serifs, wrong genre for news), Atma / Baloo Da 2 / Galada (display faces, unusable at 17px).
- **Verified 7/7** again after the swap; built site serves both WOFF2 files (200), CSS references SolaimanLipi, zero stale references to the old families.

## `docs/assets-prompt.md` — AI visual asset prompt library (Google Flow)

- **Request:** owner asked for prompts for ALL news visuals, to generate in Google Flow; wanted every type of instruction and every type of news documented.
- **Researched first (authoritative sources):** DeepMind Veo prompt guide, Google Flow 5-tips blog, Gemini API Imagen docs.
- **Key facts established:**
  - Google Flow = Google Labs product bundling **Imagen** (images), **Veo** (8s video), **Gemini** (prompt help). Features: Text-to-Video, Ingredients-to-Video (3 refs, Veo 2 only), Frames-to-Video, Scenebuilder (Jump To/Extend, Veo 2 only).
  - **Imagen prompts are ENGLISH-ONLY, max 480 tokens** — even though the site is Bengali-only. Editors write Bengali headlines, prompts stay English.
  - **Imagen text rendering is capped at ~25 chars, 2–3 phrases, unreliable fonts.** Bengali conjuncts would garble → **hard rule: generated images contain ZERO text**; all headlines/labels overlaid via HTML/CSS. Also means one image is reusable across headlines and stays accessible/selectable.
  - Aspect ratios: `1:1`, `3:4`, `4:3`, `9:16`, `16:9` (default 1:1). `imageSize` 1K/2K. `numberOfImages` 1–4.
  - **No negative-prompt parameter exists.** Only exclusion control is `personGeneration` (`dont_allow` / `allow_adult` default / `allow_all` — banned in EU/UK/CH/MENA). Exclusions must be phrased as positive instructions ("plain background with no text").
  - All Imagen output carries a **SynthID** watermark (invisible to readers — disclosure is a separate editorial duty).
- **Ethics section written prominently (§2):** never generate photorealistic images of real events, real named people, or children; always disclose AI-generated imagery in the CMS caption (`AI-জেনারেটেড ছবি`); when a real photo is needed, use a real photo or run text-only. A generated photorealistic image of a real disaster is the fastest way to destroy a news brand.
- **Document covers:** Flow overview, red lines, Bengali constraints, the prompt formula (subject+action+setting+composition+camera+lighting+style+mood+negative space+quality), full instruction vocabulary (§5), house visual style (§6), asset specs + ratios per placement + file naming (§7), prompt library for all 8 education categories + ~14 general news types + seasonal + UI/functional assets (§8), video/Veo (§9), workflow (§10), QA checklist (§11), quick-reference card (§12).
