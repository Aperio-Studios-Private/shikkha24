## Blocking defects found (3) and fixed

1. **`pnpm audit --audit-level=high` was FAILING** — a blocking CI step
   (`.github/workflows/ci.yml:141`). Two **high** advisories in `sharp`, pinned at
   `0.34.2` directly in `cms/package.json`. Patched `0.35.4` was **already in the
   tree** (via astro + next), so this was a dedupe, not a new dependency.
   Fixed → `2 low | 3 moderate`, zero high/critical. Lockfile now resolves only
   `sharp@0.35.4`.

2. **171 broken internal links across 82 pages.** The footer legal strip
   hardcoded `/page/privacy-policy`, `/page/terms-of-use`, `/page/contact`.
   `/page/[slug]` is CMS-driven and the `pages` collection is **empty**, so
   `dist/page/` was never generated. `/contact` already existed as a static page.
   Fixed by adding static `privacy-policy.astro` + `terms-of-use.astro` (Bengali,
   describing what the site actually collects — read from the code), repointing
   the footer, and registering both in the sitemap.

3. **`og:image` was a RELATIVE URL** (`/og-default.svg`). The OG protocol requires
   absolute; Facebook/X/WhatsApp/LinkedIn silently ignore relative values, so
   every page shared with no preview. Fixed in `Layout.astro` — resolved against
   `PUBLIC_SITE_URL`, already-absolute URLs left untouched.

## Environment trap (NEW — added to sandbox-build-traps)

**pnpm's `runDepsStatusCheck` auto-runs `pnpm install` before every `pnpm run`
when the lockfile differs from node_modules.** In this sandbox that install hits
`[CODEBUDDY_BROKER_DENY] EEXIST ... ~/Library/pnpm/store/v11/projects/<hash>`
(forceSymlink cannot overwrite) and **hangs indefinitely** — it also silently
kills `pnpm dev:cms` and `pnpm run build:*`.

Workaround that works: **`PNPM_CONFIG_VERIFY_DEPS_BEFORE_RUN=false`** (plus
`--config.verify-deps-before-run=false`). Removing the stale symlink alone is not
enough — pnpm recreates it and the next run denies again.
